# Data sources

| Need | Canonical source | Rule |
| --- | --- | --- |
| Competition overview, rules, and data | [Detect Suspicious Value Transfers in Poker](https://www.kaggle.com/competitions/detect-suspicious-value-transfers-in-poker) | Sign in, accept the rules, and download only into a private working directory. |
| Official metric | The competition's metric notebook/page | Refer to the official source; do not treat copied local reference material as a redistributable dependency. |

Neither the official input tables nor derived player-/hand-level tables are
redistributed by this repository.
