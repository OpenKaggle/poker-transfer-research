# Contributing

OpenKaggle welcomes careful notebooks, reproducible scripts, compact baselines,
corrections, and research notes. Start with a small, reviewable change and
explain what was tested.

Please do not commit private credentials, raw organizer data, or files whose
competition terms prohibit redistribution. Link to the official source and
keep hashes, schemas, and derived evidence when that is the useful public
artifact.

## Cite this repository

GitHub's **Cite this repository** action reads the canonical files below. For a
copyable citation, use [`CITATION.bib`](CITATION.bib) or [`CITATION.cff`](CITATION.cff);
please preserve the version and snapshot URL when citing a specific release.
